# Personal web design portfolio

A small website I use to share my front-end work and design practice.

**Website:** https://github505050.github.io/Portfolio/

## What's inside

- A responsive homepage, image gallery, project sections and light/dark mode
- A personal project gallery featuring this portfolio and my French Classroom website
- HTML, CSS, JavaScript and Bootstrap

The project gallery includes visual design exercises. Some images and old résumé details are illustrative or out of date. These examples are not presented as completed paid-client commissions.

## Upwork case study

The [public design preview](https://github505050.github.io/Portfolio/upwork-showcase.html) has no personal contact information or external contact links. It uses sample UI views rather than screenshots of commissioned work.

## Testing

GitHub Actions runs the Playwright browser checks in `scripts/portfolio-smoke.cjs` and exports the case-study screenshots into `showcase-shots/`.

The website runs as a static site on GitHub Pages. No backend is required.
